# Changelog

## 0.1.0

- Initial release.
- Strongly typed design tokens: `AppColorTokens`, `AppSpacingTokens`, `AppRadiusTokens`, `AppSizeTokens`, `AppMotionTokens`, `AppTypographyTokens`.
- Aggregate `AppDesignTokens` with `.light` and `.dark` static constants.
- Full `copyWith` and `lerp` support on all token classes.
