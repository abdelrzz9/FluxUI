# flutter_ui

**Compatibility re-export of [`fluxui_kit`](../fluxui/README.md).**

This package re-exports everything from `fluxui_kit` for projects that prefer the
`flutter_ui` package name. New projects should use `fluxui_kit` directly.

Part of the [FluxUI](https://github.com/abdelrzz9/FluxUI) monorepo.

---

## Installation

```yaml
dependencies:
   fluxui_kit: ^0.1.0
```

---

## Usage

```dart
import 'package:flutter_ui/index.dart';
// or
import 'package:flutter_ui/flutter_ui.dart';
```

All components, theme APIs, and tokens from `fluxui_kit` are available.

For full documentation see the [`fluxui_kit` README](../fluxui/README.md).

---

## Requirements

- Dart SDK `>=3.4.0 <4.0.0`
- Flutter `>=3.24.0`
